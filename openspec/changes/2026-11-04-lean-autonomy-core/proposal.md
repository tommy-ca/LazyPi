# Use an autonomy-first default catalog

## Why

The current default selects packages with distinct capabilities, but several are optional conveniences rather than required for the chosen autonomy-first control plane.

## What changes

- Keep subagents, ask-user, skillful, goal, web access, and dynamic workflows in the default core.
- Move skill mentions, side chat, context usage, simplify, FFF, and Ponytail to the optional tier without removing catalog entries or user data.
- Preserve selectors and full-catalog management. Align help, documentation, and verification with the new default.
