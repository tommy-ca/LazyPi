# Default Web Access in the essentials catalog

## Why

The approved S13 clarification says "approve, web access should be default on". Keep the six existing ordered entries, but make Web Access core rather than optional. Other retired or conflicting packages stay outside curation.

## What Changes

- Select PStack, Subagents, Sandbox, Verdict, Ask User, and Web Access by default and in the picker.
- Keep core/optional selector compatibility with optional empty, including no setup or settings changes for an empty selection.
- Update help, status expectations, active catalog documentation, and specification projections.
- Let the packed driver accept the empty optional step without changing the existing workflow or frozen native probe.

## Impact

Only the Web Access category changes in PACKAGES. Identity matching, resolveSelection, pins, object metadata, order, scopes, unmanaged registrations, broad updates, and raw removal passthrough remain unchanged. This unpublished registration candidate does not establish native loading, authorization, recovery, or readiness. Native probe versions, package exclusions, authority, and publication gates remain unchanged.
