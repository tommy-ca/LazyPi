# Unpublished minimal PStack registration and catalog retirement

## Why

The accepted local target requires canonical PStack with Subagents, Sandbox,
Verdict, and Ask User support, with Web Access optional for research. Previous
installer and control-plane contracts disagree on counts and promise capabilities
that leave curation. Canonical resource closure and native runtime are not proven.

## What Changes

- Replace the flat candidate catalog with five required registrations and one optional.
- Separate canonical identity from the audited fresh argument. Preserve old pins.
- Retire all other current catalog IDs, not their installed state or data.
- Preserve raw removal passthrough. Retired IDs reject only in install selectors,
  and no longer resolve current or legacy sources on removal.
- Keep builtin models, npm semantics, broad updates, scope, and settings helpers.
- Align help, active docs, both specifications, exact-source assertions, and the
  existing packed verifier. Replace BTW migration stages with registration and
  exact-source removal coverage, retaining builtin-model checks.
- Retire unsupported capability promises. Mark old package pages historical.

## Impact

Affected specs: `lazypi/installer`, `harness/control-plane`.
Affected implementation: catalog/fresh-install arguments, packed driver and
source assertion, public CLI fixtures, docs/navigation, verification recipes.

This is an unpublished candidate, not default promotion, release, native loading,
security certification, or shipping. No copied canonical assets, adapter, second
catalog, package allowlist changes, automatic conflict exclusion, or dependency
installation is included. Sandbox remains disabled until explicitly configured.
Untrusted or unattended work still requires a container or VM. Real-session and
operator acceptance remain required before promotion.
