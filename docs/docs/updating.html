Updating

Keep your LazyPi packages current.

Update installed packages

npx @tommy-ca/lazypi update

This runs Pi's updater for installed package changes.

What the update does

When you run update, LazyPi:

  1. Runs pi update for installed Pi packages

Update preserves your selected catalog footprint.

Repairing a broken package

A catalog package can be present in settings.json yet fail at runtime with a missing-dependency error (for example Cannot find module 'acorn') when its dependency footprint is incomplete on disk — typically a stale checkout under ~/.pi/agent/extensions/ without its node_modules.

  1. Run npx @tommy-ca/lazypi update (or pi update) to repair installed footprints.
  2. If the error persists, reinstall the package, or remove the stale checkout directory (for example ~/.pi/agent/extensions/subagent) — Pi loads that package from its npm store instead.

Your package settings are preserved; LazyPi does not manage files inside ~/.pi/agent/extensions/.

If a failure persists after a repair, the installed version may simply be old: pi update respects the version pins in settings.json (for example npm:pi-subagents@0.58.0) and does not advance them. Reinstall at the version you want with pi install npm:<pkg>@<version> (or without the pin to track latest). npx @tommy-ca/lazypi status shows the installed pins.
