Installation

Get LazyPi running in under a minute.

Prerequisites

  • Node.js 20 or later for the LazyPi CLI
  • npm (bundled with Node.js)

Pi and individual extensions can require a newer runtime. For example, the current pi-skillful and pi-web-access packages declare Node.js 22.19 or later. Check the requirements for the versions you install and the runtime used to launch Pi.

You do not need to install LazyPi globally. npx downloads and runs it on demand.

Run it

npx @tommy-ca/lazypi

That's the entire install command. LazyPi will:

  1. Check whether Pi is installed on your system
  2. Install Pi if it's missing
  3. Show an interactive picker: Install everything or select individual packages
  4. Install your selection and confirm what's ready

Install everything vs. interactive picker

Choosing Install everything on a TTY installs the full 18-package catalog (12 core plus the optional tier). --yes with no other flags installs the 12 harness-core packages only; add the optional tier with --only optional or the picker.

The interactive picker lets you browse the catalog and select only what you want. Use arrow keys to navigate, space to toggle, and enter to confirm.

Idempotency

LazyPi skips installed packages. Selecting subagents also sets model: "" for context-builder, planner, researcher, reviewer, scout, and worker, even when the package is already installed. They inherit the session model when no higher-precedence model override applies. Other override keys remain unchanged. A re-run is a no-op when the selected packages and these overrides are already present.

No global LazyPi installation is required. Runner caches can persist and may serve an older release. See the FAQ for cache troubleshooting. Installed Pi packages, settings overrides, and timestamped settings backups also persist.

Before LazyPi changes an existing settings file, it saves a sibling backup named settings.json.lazypi.<timestamp>.bak. Package removal does not delete these backups or runner caches.

After installation, head to First Steps to launch Pi, authenticate, and try a few commands that show what changed.
