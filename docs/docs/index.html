LazyPi

One command to get a complete, curated Pi coding agent setup.

What is LazyPi?

Pi is a minimalist coding agent. That minimalism is intentional — it ships as a blank canvas and lets the community build on top of it. The result is a rich ecosystem of packages: skills, themes, MCP adapters, memory systems, prompt templates, sub-agents, cost trackers, and engineering frameworks.

LazyPi is the fastest path into that ecosystem. Run one command and you get a curated selection of the community's best work, pre-configured and ready to use. No research, no manual installs, no configuration tax.

It's designed to be safe to re-run — LazyPi is idempotent by default. It skips anything already installed and never overwrites your existing configuration.

What it installs

LazyPi installs the 12-package harness core by default, plus a 5-package optional tier when you ask for it. Catalog philosophy explains why 12 is default, why 5 are optional, and what it takes to join.

Category What you get
Core (harness core) Sub-agents, a structured ask gate, skill visibility, $ skill mention, a long-objective gate, side chat, context budgeting, simplify, web research, FFF search, a workflow engine for sub-agent fan-out, and ponytail discipline review
Optional (on request) Targeted LSP diagnostics and fixes, interactive shell overlays, autonomous research loops, structured todo tracking, and markdown-backed memory — installed with --only optional or the interactive picker

Dropped packages

Skill arguments, MCP, ralph-wiggum, curated-themes, and the rest of the Dropped list are outside the catalog. pi install still works. LazyPi does not manage them. See Catalog philosophy for the membership bar and the closed list.

Quick start

LazyPi runs via npx — no global install required:

npx @tommy-ca/lazypi

LazyPi will check if Pi is installed, install it if not, then show you an interactive picker. Choose Install all for the full setup, or select individual packages.

Once installation finishes, continue with First Steps to authenticate Pi and try a few high-value commands.

Commands

Command What it does
npx @tommy-ca/lazypi Interactive install — install all or pick packages
npx @tommy-ca/lazypi update Run pi update for installed packages
npx @tommy-ca/lazypi remove Interactive picker to remove packages
npx @tommy-ca/lazypi remove <id> Remove a specific package by ID
npx @tommy-ca/lazypi status Show installed, missing, and extra packages
npx @tommy-ca/lazypi doctor Check the environment for common problems
