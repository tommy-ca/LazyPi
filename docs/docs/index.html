LazyPi

Unpublished registration candidate. Native integration and readiness remain unverified.

What is LazyPi?

Pi is a minimalist coding agent. That minimalism is intentional — it ships as a blank canvas and lets the community build on top of it. The result is a rich ecosystem of packages: skills, themes, MCP adapters, memory systems, prompt templates, sub-agents, cost trackers, and engineering frameworks.

LazyPi curates package registrations. Registration does not establish effective loading, role binding, authorization, tool dispatch, or recovery. Sandbox remains disabled until explicitly configured. Ask User is not hard approval. Untrusted or unattended work requires a container or VM.

LazyPi skips packages already installed. Selecting subagents also resets six builtin model overrides to the session-model fallback, even on a re-run. Other override keys are preserved. Before changing an existing settings file, LazyPi creates a timestamped backup. See Installation for the settings details.

What it installs

The candidate selects all six core registrations by default, including Web Access. Catalog philosophy explains retirement, deliberate capability losses, and the native/operator evidence still required for promotion.

Category What you get
Core (harness core) PStack canonical checkout reference, Subagents, Sandbox, Verdict, Ask User, and Web Access. Canonical pins are preserved, not forced forward.
Optional (empty) The selector remains valid. --only optional skips setup and changes nothing; --except optional selects all six.

Dropped packages

All other previous catalog entries are retired from curation, not uninstalled or disabled. Installed registrations remain Other with pins, metadata, order, scope, and data preserved. Broad updates still include them. Retired IDs reject in install selectors, but removal still passes unknown targets unchanged to Pi. Use exact installed sources because retired IDs and legacy mappings no longer resolve. pi install still works for unmanaged packages.

Quick start

LazyPi runs via npx — no global install required:

npx @tommy-ca/lazypi

Choose Install everything for the full 6-package catalog, or select individual packages. After selection, LazyPi offers to install Pi if needed. Cancelling selection or selecting no packages skips Pi bootstrap and package installation.

Continue with First steps to distinguish registrations from runtime evidence. Offline checks do not certify native readiness.

Commands

Command What it does
npx @tommy-ca/lazypi Interactive install — Install everything or pick packages
npx @tommy-ca/lazypi update Run pi update for installed packages
npx @tommy-ca/lazypi remove Interactive picker to remove packages
npx @tommy-ca/lazypi remove <id> Remove a specific package by ID
npx @tommy-ca/lazypi status Show installed, missing, and extra packages
npx @tommy-ca/lazypi doctor Check the environment for common problems
