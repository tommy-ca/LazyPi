Removing

Remove individual packages or the entire LazyPi setup.

Interactive picker

npx @tommy-ca/lazypi remove

Opens a multi-select picker showing installed LazyPi packages with nothing selected. Use space to select packages to remove, then enter to confirm. An empty selection removes nothing.

Remove by ID

npx @tommy-ca/lazypi remove subagents

Resolves a current catalog ID to exact matching installed sources, including pins. Retired IDs no longer resolve catalog or legacy sources. Unknown targets still pass unchanged to Pi, so remove btw forwards pi remove btw. It does not resolve npm:pi-btw@0.1.0. Use the exact installed source instead.

Remove by raw source

npx @tommy-ca/lazypi remove npm:pi-subagents@0.13.3

Removes a package using its exact source specifier. This remains available for unmanaged and retired registrations. For example, use npx @tommy-ca/lazypi remove npm:pi-btw@0.1.0. No raw-target grammar change or retired compatibility list is introduced.

Curation retirement is not removal

Retiring a catalog entry does not uninstall or disable an active package, delete data, or prevent updates. Installed strings, objects, pins, metadata, order, scope, and unrelated settings remain. Retired registrations appear as Other and stay eligible for broad pi update --extensions. Declared source conflicts do not trigger automatic uninstall or exclusion.

Removing LazyPi itself

LazyPi does not require a global installation. Removing packages does not remove runner caches, subagent settings overrides, or LazyPi's timestamped settings backups. See Installation for the persisted settings and backup names, and the FAQ for cache troubleshooting.
