Goal

An explicit long-objective gate: Pi stops on done, blocked, or an external wait.

What it does

/goal <objective> sets an explicit session objective. While a goal is active, Pi reports progress with three tools instead of drifting between steps:

Tool When
goal_complete Evidence-backed summary for the active goal id
goal_blocked Repeated impasse, with reason, evidence, and repeated turns ≥ 3
goal_wait External event arranged; optional resume_after_ms

Why it's included

Long tasks fail by slow drift, not sudden error. A goal gate replaces the checkbox todo anti-pattern: the agent stops when the objective is met, stalls, or waits on the world — and says which, with evidence. Config lives in ~/.pi/agent/pi-goal.json (automaticTurns, noProgressTurns).
