Goal

Historical, unmanaged package. Long-objective stopping on done, blocked, or external wait is deliberately no longer curated. Canonical checkout registration does not replace this behavior.

Existing registrations and data remain. Retirement does not disable packages or freeze updates. The retired ID rejects in install selectors and no longer resolves catalog or legacy sources for removal. Use the exact installed source.
