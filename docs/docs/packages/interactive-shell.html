Interactive Shell

Run interactive CLIs, coding agents, and auth flows in pi TUI overlays.

Optional catalog package — install with npx @tommy-ca/lazypi --only interactive-shell or pi install npm:pi-interactive-shell.

What it does

pi-interactive-shell spawns supervised subprocesses in an overlay TUI: interactive mode for typed input and approval, hands-free mode where you can take over at any time, dispatch mode for fire-and-forget delegation with completion notifications, and monitor mode for headless structured event watching.

It is the natural home for CLIs that need live supervision — npm device-auth publish flows, long-running TUI agents, or commands that need a human to approve a step.

Why it's included as optional

Re-evaluated under the promotion audit 2026-08-29 and deliberately kept out of the core default: it is operator-workflow tooling (TUI/overlay chrome) rather than harness control plane, and every session doesn't need it. It stays fully managed by the catalog so status, install, and remove cover it.
