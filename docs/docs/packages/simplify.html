Simplify

Reviews recently changed code for clarity, consistency, and maintainability.

Optional catalog package. Install with npx @tommy-ca/lazypi --only simplify.

What it does

Pi-simplify reviews changed code and suggests improvements to clarity and consistency while aiming to preserve behavior.

Review its changes and run appropriate tests. Like any code change, a simplification can introduce a regression.

Why it's included

Implementation and cleanup are cognitively different tasks. Trying to do both at once usually means the cleanup doesn't happen. Simplify makes it a one-command step after implementation — run it, review the diff, and you're done.

Commands

CommandWhat it does
/simplify Review all uncommitted changes
/simplify --staged Review only staged changes
/simplify src/foo.ts src/bar.ts Review specific files
/simplify --ref=main Diff against a specific branch and review those changes
