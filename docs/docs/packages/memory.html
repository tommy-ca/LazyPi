Memory

Letta-like, git-backed markdown memory: persistent context across sessions.

Optional catalog package — install with npx @tommy-ca/lazypi --only memory or pi install npm:pi-memory-md; installs of the older git source migrate automatically.

What it does

pi-memory-md gives Pi a durable knowledge layer: context, preferences, and decisions stored as git-backed markdown with full history, a memory index appended to the prompt at session start, on-demand reads via tools, and separate memory spaces per project.

Why it's included as optional

Re-audited 2026-08-29: the operator's harness uses it daily (memory tools and skills active across sessions), and it publishes to npm (0.1.38) — consistent with the floating-npm convention. It is harness infrastructure rather than control plane, so it stays optional and installs on request.

The audit also evaluated npm:pi-memory (jayzeng's qmd-powered semantic-search memory, the most popular on the pi package directory): compelling and maintained, but a second memory substrate would duplicate the installed daily driver with a different data format. The lean harness ships one memory implementation — see openspec/explorations/memory-audit.md for the comparison.
