Memory

Auto-managed markdown memory: capped MEMORY.md/USER.md stores with frozen session snapshots.

Optional catalog package — install with npx @tommy-ca/lazypi --only memory or pi install npm:@henryqw/pi-memory; LazyPi replaces registrations of the older npm and git sources.

What it does

@henryqw/pi-memory gives Pi auto-managed markdown memory: capped MEMORY.md and USER.md entry stores with frozen session snapshots. It uses the pi 1.5.0 native API and is actively maintained.

The package replaces the older pi-memory-md, which has not been updated since May 2026. LazyPi replaces the legacy package registration after installing the replacement. It does not convert stored memory content.

Setup

Memory requires Pi 1.5.0 or later in the 1.x series. Install npm:@henryqw/pi-ask-question and npm:@henryqw/pi-task-models separately, then configure a balanced model in /task-models. These companion extensions are not installed by LazyPi's memory selection.

Why it's included as optional

Memory is harness infrastructure rather than control plane, so it stays optional and installs on request. The catalog now manages install, status, remove, and source migration for it.
