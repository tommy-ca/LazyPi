Ponytail

Lazy senior dev mode: minimal, stdlib-first code with /ponytail review, audit, and a debt ledger.

What it does

Ponytail puts a lazy senior dev inside your agent: a discipline mode that makes the agent stop at the first rung of a stdlib-first ladder before writing code — does this need to exist, is it already in this codebase, does the stdlib or a native platform feature cover it, is it an installed dependency, can it be one line — and only then write the minimum that works. The result is minimal diffs, never golfed: validation, error handling, security, and accessibility are never on the chopping block.

Deferred shortcuts use shortcut: annotations by default and can be collected into a debt ledger. Review covers bugs, security, tests, performance, and unnecessary complexity; audit covers the whole repo. Level switches (/ponytail lite|full|ultra) tune how aggressively the ruleset is enforced, and the ruleset is injected into subagents too.

Why it's included

LazyPi ships a deliberately lean catalog — a curated core instead of everything the ecosystem has to offer. Ponytail codifies that anti-over-engineering ethos as an always-on discipline: it keeps the agent from rebuilding what's already in the harness and holds the line against speculative scaffolding creeping back in.

Commands

CommandWhat it does
/ponytail lite|full|ultra Set the enforcement intensity (no argument reports the current level)
/ponytail-review Review the current change for correctness, risk, performance, tests, and unnecessary complexity
/ponytail-audit Review the whole repo, not just the diff
/ponytail-debt Collect deferred shortcut: comments into a debt ledger; a custom marker can be specified
/ponytail-gain Show the measured impact scoreboard — less code, less cost, more speed
/ponytail-help Quick reference for the commands above
