Web Access

Web search, content extraction, and video understanding via Exa, Perplexity, and Gemini.

What it does

Pi-Web-Access gives Pi the ability to search the web, fetch and extract page content, and understand video — without requiring browser automation. It exposes four tools that Pi invokes directly: web_search, source_check, fetch_content, and get_search_content.

The package is zero-config when used via Exa MCP. It also supports Perplexity and Gemini as providers, with smart fallback across them. Specialized capabilities include YouTube video understanding, local video file analysis, GitHub repository cloning for deeper inspection, and PDF extraction.

Web Access is a core registration selected by default with --yes, --only core, and the picker. Use --only web-access to select it alone, or --except web-access to select the other five. The optional category is empty, so --only optional installs nothing. This remains an unpublished registration candidate. Registration does not prove loaded tools, provider behavior, or native readiness.

Why it's included

A coding agent that can't look things up has to rely entirely on training data. That's a significant limitation for anything involving recent library versions, documentation, Stack Overflow answers, or API references. Web Access makes Pi a genuinely useful research partner, not just a code completer.

Commands

Pi can invoke these default tools directly. Tool availability and names can be configured.

ToolWhat it does
web_search General web search across providers
source_check Gather passage-level evidence for a claim
fetch_content Fetch and extract content from a URL
get_search_content Retrieve stored content from earlier searches or fetches
