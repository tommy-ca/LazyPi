BTW

Historical, unmanaged side-chat package. Side-thread isolation is deliberately no longer a curated capability. PStack registration does not prove equivalent behavior.

Existing registrations remain Other with pins, metadata, and data intact. Retirement does not disable active packages or prevent broad updates. No automatic migration from npm:pi-btw to npm:@narumitw/pi-btw remains. The ID rejects in install selectors. Removal still passes unknown targets unchanged to Pi, so use the exact installed source, not remove btw.
