LSP

Targeted Language Server Protocol diagnostics and source fixes.

Optional catalog package — install with npx @tommy-ca/lazypi --only lsp or pi install npm:@narumitw/pi-lsp.

What it does

pi-lsp exposes lsp_diagnostics and lsp_fix: targeted LSP diagnostics with exact ranges and server-provided source actions (such as fixAll or organizeImports), without running a full-project check for every intermediate edit. Language servers are configured in JSON by command and file extension, start only while a tool call needs them, and shut down afterwards — no editor-like persistent session.

It is most useful when a full lint or typecheck is slow but a few files need intermediate feedback, or when a language server offers a source action worth applying. It does not replace the repository's authoritative format, lint, typecheck, build, and test commands — those stay the final word.

Why it's included as optional

Promotion audit 2026-08-29: actively maintained (@narumitw, the same author as BTW and Goal), lean-philosophy aligned, and runtime-verified (prebuilt node-pty bindings). It qualified for the catalog but not the core default — it adds the most value only when your repo's own checks are slow, so it sits in the optional tier pending demonstrated daily-driver use.
