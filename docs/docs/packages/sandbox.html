Sandbox

Required sandbox support in an unpublished candidate, disabled until explicitly configured.

Registration is not configuration

LazyPi registers npm:pi-better-sandbox without changing sandbox settings, enabling switches, or altering container controls. Installing the package alone does not establish containment, child interception, fail-closed headless behavior, or a safe unattended environment.

The canonical recommendation is static-only. Local required support is stricter than upstream's capability minimum, but required registration is not a runtime certification.

Security limits

Packages run with Pi's privileges. Untrusted or unattended work requires a container or VM. A private HOME is not OS containment. Native loading, actual denial, independent child authorization, exit/recovery, and operator promotion remain unverified. Review the package's configuration in a separately authorized environment before relying on it.
