FFF

Fuzzy file and content search: FFF-powered fffind, ffgrep, and fff-multi-grep alongside the built-in tools.

What it does

This package adds a Rust-native, SIMD-accelerated search index (FFF) as additional tools — it does not replace Pi's built-in find and grep:

Tool What it does
fffind Fuzzy file-name search, frecency-ranked, typo-tolerant, git-aware
ffgrep SIMD content search with smart case, context lines, and cursor pagination
fff-multi-grep OR-logic multi-pattern content search via Aho-Corasick

No subprocess per call (no fd/rg spawning): files are indexed in the background at session start, and access history (frecency) ranks results across sessions. /fff-health shows index status; /fff-rescan reindexes.

Why it's included

The harness's context-hygiene rule: unbounded grep dumps flood the transcript. ffgrep pages results with a cursor (default 100), so searches stay bounded and the agent reads then continues. For $HOME-launched sessions with huge trees, disable home indexing with FFF_ENABLE_HOME_SCAN=0.
