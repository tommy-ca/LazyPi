Pi Verdict

Claude Code-style permission gate: allow, deny, or ask per tool call with an LLM classifier.

What it does

Pi Verdict adds a permission gate to Pi that runs before every tool call. It classifies each action as allow, deny, or ask, using built-in dangerous rules, your own allow/deny rules, and an LLM classifier that carries session context. Uncertain or failed classifications always fail closed.

The gate protects itself against tampering and inspection. It is a permission gate, not a sandbox: use OS-level isolation on top of it.

Why it's included

Pi has no built-in per-tool permission confirmation. Every tool call runs with Pi's own privileges. Pi Verdict adds the missing safety layer, modeled on Claude Code's auto mode, so routine actions flow through while dangerous or ambiguous ones stop for review.
