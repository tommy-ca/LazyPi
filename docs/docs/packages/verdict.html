Pi Verdict

Claude Code-style permission gate: allow, deny, or ask per tool call with an LLM classifier.

What it does

Pi Verdict adds a permission gate to Pi tool calls. It uses built-in dangerous rules, your own allow/deny rules, and an LLM classifier that carries session context. Uncertain or failed classifications fail closed. Configured ignoreTools exemptions can allow uncovered tools without classification; review those exemptions before relying on the gate.

The gate includes self-protection against tampering. It does not guard manual ! shell escapes or contain malicious code. It is a permission gate, not a sandbox; use OS-level isolation on top of it.

Verdict is required support in this unpublished candidate, not a guarantee of fail-closed headless or child behavior. Registration and offline fixtures do not prove effective loading or authorization. Sandbox configuration and OS containment remain separate requirements.

Why it's included

Pi has no built-in per-tool permission confirmation. Every tool call runs with Pi's own privileges. Pi Verdict adds the missing safety layer, modeled on Claude Code's auto mode, to help control routine, dangerous, and ambiguous actions. Its configured exemptions and security limits still apply.
