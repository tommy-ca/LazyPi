Packages

Sixteen catalog packages: the twelve-package harness core and a four-package optional tier installed on request.

core
Sub-agents
Spawn specialized sub-agents with chains, parallel execution, and async support
 core
Ask User
Structured ask gate: stop and ask instead of guessing
 core
Pi Skillful
Skill visibility: discover above the git root, hide unused skills
 core
Mention Skill

 core
Web Access
Web search, content extraction, and video understanding via Exa, Perplexity, and Gemini
 core
Simplify
Reviews changed code for clarity and consistency — never changes behavior
 core
Goal

 core
Context Usage
See what is burning the context window before it fills
 core
BTW
Side conversation channel running a full Pi sub-session in a modal overlay
 core
FFF
Fuzzy file and content search: fffind, ffgrep, fff-multi-grep
 core
Dynamic Workflows
Fan work out across subagents: /workflows TUI, deep-research, resume, token accounting
 core
Ponytail
Lazy senior dev mode: /ponytail review, audit, and a debt ledger
 optional
LSP
Targeted LSP diagnostics and source fixes with configurable language servers
 optional
Interactive Shell
Run CLIs and coding agents in TUI overlays with interactive and hands-free supervision
 optional
Autoresearch

 optional
Todos
