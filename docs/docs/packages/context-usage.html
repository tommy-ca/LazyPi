Context Usage

See what is burning the context window before it fills.

What it does

/context shows a dot grid of context consumption and /context details breaks down what is resident (system prompt, tools, turns). When the window is close to full, compact, or move work onto a fresh lane (an isolated fresh child or a new session) instead of stuffing the same transcript.

Why it's included

Context budget is the silent failure mode of long agent sessions: the transcript fills, quality drops, and the cause is invisible until it's too late. A live budget view makes compaction a deliberate act instead of a surprise.
