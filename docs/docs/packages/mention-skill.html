Mention Skill

$ skill mention: hidden skills stay reachable from the prompt.

What it does

Type $ for fuzzy skill autocomplete, then $skill-name expands the skill's content into the prompt before the model sees it. Slash-command skill entries stay out of autocomplete clutter, and settings are configurable via the package's settings schema. 

$tdd implement the parser
$research + $code-review after the change

Why it's included

The harness keeps skill bodies out of the system prompt — which only works if hidden skills stay explicitly reachable. The $ mention is that handoff: skills stay invisible to automatic discovery and still invokable on demand. The harness spec installs exactly one mention implementation; this is it.
