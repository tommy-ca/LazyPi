Pi Skillful

Skill visibility: discover skills above the git root and hide unused ones.

What it does

Stock Pi stops .agents/skills/ discovery at the git repo root. pi-skillful walks ancestors to the filesystem root — matching how AGENTS.md layers — and lets you hide unused skills so they never enter the automatic skill-discovery prompt. It also expands /skill:name inline anywhere in a prompt.

Hide skills you don't want visible: 

{
  "skillful": {
    "hiddenSkills": ["resume", "pptx", "xlsx"]
  }
}

Why it's included

The harness rules say only name + description of 4–6 weekly skills should sit in the system prompt. Visibility control is how that stays true: hidden skills load on demand, so prompt drift and wrong-skill routing stay out of the picture.
