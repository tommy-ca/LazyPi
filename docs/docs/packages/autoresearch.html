Autoresearch

Autonomous experiment loops: iterate toward a measurable optimization target.

Optional catalog package — install with npx @tommy-ca/lazypi --only autoresearch or pi install git:github.com/davebcn87/pi-autoresearch (pinned in the catalog).

What it does

Autoresearch sets up and runs an optimization loop for any measurable target: it gathers what to optimize, then iterates experiments with pre/post-iteration hooks, convergence tracking, and finalize passes that collapse the best candidates into clean, reviewable branches.

Use it when a metric rewards systematic experimentation — clustering quality, search relevance, prompt quality — and you want the loop to run itself while you review the survivors.

Why it's included as optional

Research-loop automation is a convenience layer, not harness control plane, so the promotion audit 2026-08-29 kept it out of the core default. It is pinned to a commit in the catalog so installs stay reproducible, and status/install/remove cover it like any other catalog package.
