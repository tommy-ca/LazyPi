Todos

Structured todo list management: track multi-step work with live progress widgets.

Optional catalog package — install with npx @tommy-ca/lazypi --only todos or pi install npm:pi-manage-todo-list; installs of the older git source migrate automatically.

What it does

pi-manage-todo-list gives Pi a structured todo list — VSCode-Copilot-Chat inspired — for multi-step work: live progress widgets, session persistence, and the classic manage-todo-list tool so agents can plan, update, and close out checklists visibly instead of silently.

It is not a verbatim checkbox contract: items reflect the current plan, get marked done the moment their step is finished, and disappear when the work no longer needs them. The plan stays alive, not the paperwork.

Why it's included as optional

Re-audited 2026-08-29 on real evidence: 75 tool-call sites across four session histories — the operator's harness genuinely uses structured tracking for multi-step work. It is operator-workflow tooling rather than control plane, so it stays in the optional tier (not core), but the catalog now manages install, status, remove, and source migration for it. The earlier "checkbox anti-pattern" drop rationale applied to verbatim checklist contracts, not this tracker's usage pattern.
