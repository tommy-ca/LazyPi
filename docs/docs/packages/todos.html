Todos

Persistent todo overlay: a task list that survives reload and compaction.

Optional catalog package — install with npx @tommy-ca/lazypi --only todos or pi install npm:@juicesharp/rpiv-todo; installs of the older git and npm sources migrate automatically.

What it does

@juicesharp/rpiv-todo gives Pi a persistent todo overlay rendered as a live panel above the editor. The list is rebuilt from the conversation itself, so it survives /reload and compaction. It adds a todo tool and a /todos command.

Tasks show completed, in-progress, and pending rows with activity labels. The plan stays alive across long research, design, and implement sessions.

Why it's included as optional

Structured tracking for multi-step work is operator-workflow tooling rather than control plane. The catalog now manages install, status, remove, and source migration for it. The package is actively maintained and replaces the older pi-manage-todo-list, which is no longer updated.
