Skill Args

Skills take arguments like shell commands — $1, $ARGUMENTS, and inline !`cmd` expansion.

What it does

Pass arguments to a skill the way you pass them to a shell command: $1, $2, $ARGUMENTS and ${@:N:L} slices split with shell-style quoting, expanded into the skill body at invocation. 

---
name: deploy
description: Deploy a service to an environment
---

Deploy service $1 to $2.
Current branch: !`git branch --show-current`
/skill:deploy api production

The model receives the body with $1 as api, $2 as production, and real command output in place of the git block — before it reads the prompt.

Why it's included

The harness skill surface is visibility (pi-skillful), mention ($, @zigai/pi-mention-skill), and parameters (skill-args). Parameterization stops one-hard-coded-copy-per-case skill sprawl and puts command evidence in the prompt instead of a tool round-trip.
