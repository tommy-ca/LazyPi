Catalog philosophy

Why the default install is 12, why 5 stay optional, and what it takes to join the catalog.

The default is 12

--yes installs the 12 core packages. That is the harness LazyPi will stand behind without a picker. Core packages are the control plane or a discipline habit. They run in the daily session, not as garnish.

Isolated sub-agents, an ask gate, skill visibility, $ mention, a long-objective gate, side chat, context budget, simplify, web fetch, paged search, workflow fan-out, and ponytail. Twelve is already a lot. Adding more by default trains people to skip the catalog.

Five are optional

On a TTY, Install everything installs all 17. The extra five are cataloged so LazyPi can install, status, update, and remove them. They are not default because they fail the core bar.

  • lsp is targeted diagnostics. Useful, not a control-plane primitive.
  • interactive-shell is TUI chrome. Chrome is not the control plane.
  • autoresearch is experiment loops. Convenience, not core.
  • todos is a structured tracker. Core forbids checkbox todos as the default posture.
  • memory is git-backed memory. Infrastructure, not a control-plane primitive.

Pick them with --only optional, the picker, or TTY Install everything.

Membership bar

A package joins the catalog only when all of these hold:

  • It is a daily driver. Installed and used in real sessions before anyone proposes it.
  • It is maintained. Recent releases on its primary channel.
  • It is control plane or discipline. Not meal-prep, chrome, or one-shot convenience.
  • Native or install-script machinery has a demonstrated runtime path.
  • It is not on the Dropped list.
  • A change spec carries the audit trail before the catalog grows.

Meal-prep, chrome, and one-shot convenience can be excellent packages. They still do not belong in LazyPi's default or optional tiers.

Dropped packages

Dropped ids are outside the catalog. pi install still works. LazyPi does not manage them. Status reports them as other Pi packages when they are present.

The closed list is compound, powerbar, extension-settings, plannotator, slopchop, usage, raw-paste, plan, add-dir, claude-cli, prompt-templates, hackerman, terminal-theme, skill-args, mcp, ralph-wiggum, and curated-themes.

Skill arguments, MCP adapters, ralph-wiggum loops, and themes are in that list. They are not LazyPi extras. They are packages this installer will not grow into.
