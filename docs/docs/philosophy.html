Catalog philosophy

An unpublished registration candidate, not certified native orchestration.

Five required, one optional

The flat candidate order is PStack, Subagents, Sandbox, Verdict, Ask User, then Web Access. The first five are required support. Web Access is the sole optional research package. --yes selects five. TTY Install everything selects six.

The canonical reference manifest is static-only and does not enforce switches. Accepted local support policy is stricter than upstream's capability minimum. Sandbox remains disabled until explicitly configured. Ask User is not hard approval.

PStack is registered as a canonical Git checkout reference, not copied resources or an owned bundle. Registration cannot prove native loading, role binding, model/tool semantics, child authorization, or recovery. The independent npm:@zenspc/pi-pstack distribution is not an alias.

Retired curation, not installed state

Retired IDsClassification and deliberate loss
pi-skillful, mention-skillSkill discovery/hiding and mention expansion leave curation. No equivalent replacement is proven.
goal, btw, context-usageObjective stopping, side chat, and context telemetry are independent capabilities deliberately retired.

autoresearch, todos, memoryExperiment loops, persistent tracking, and markdown memory leave curation.
dynamic-workflowsDeclared upstream source conflict. This is not evidence of a loaded tool collision or equivalent fan-out behavior.

There is no compatibility tier. Retired IDs reject in --only and --except before bootstrap or package commands. Existing strings, objects, pins, metadata, order, scope, and unrelated settings remain. Registrations show as Other, not migrated or uninstalled.

Subtraction does not disable active packages or prevent updates. update remains broad pi update. Retired IDs no longer resolve catalog or legacy sources for removal. Unknown targets still pass unchanged to Pi. Use exact installed sources, for example remove npm:pi-btw@0.1.0, not remove btw. No automatic conflict exclusion or uninstall occurs.

Membership and promotion

The membership bar remains control plane or discipline, not meal-prep or chrome. Promotion requires maintained packages exercised in real operator sessions, demonstrated native/install-script runtime paths, an audited change spec, and operator ratification. This offline unpublished draft does not satisfy those promotion gates.

Untrusted or unattended work requires a container or VM. A private HOME and registered sandbox package are not OS containment. Native integration, headless denial, independent child gates, exit/recovery, and readiness remain unverified.

Dropped packages

Previously Dropped packages remain outside the catalog: compound, powerbar, extension-settings, plannotator, slopchop, usage, raw-paste, plan, add-dir, claude-cli, prompt-templates, hackerman, terminal-theme, skill-args, mcp, ralph-wiggum, and curated-themes. pi install still works for unmanaged sources. LazyPi does not curate them.
